Course Description

This advanced graduate course covers classical, geometric, and deep learning methods in computer vision. It begins with the mathematical foundations of computer vision and progresses to recent deep-learning advances. Its objective is to introduce formal perception tools for students interested in robot autonomy and 3D perception.

Topics include camera sensors and calibration, image formation, single-view geometry, projective transformations, multi-view geometry, structure from motion, optical flow, computational imaging, radiance fields, volumetric rendering, and deep-learning-based depth and reconstruction methods.

Prerequisites: Linear algebra and proficiency with Python or another scripting language. Prior computer vision experience is not required.

Working in Pairs

Projects are done in pairs, but each partner should understand every part of the submission. Splitting the work so that one person writes all the code and the other writes the report means each of you misses half of what the project teaches. Some ways to divide the work:

  • Work through the core algorithm together. Pair-program the key step of each project (for example, homography estimation in P1) or implement it separately and compare results.
  • Split by role, then swap. One partner leads the implementation and the other leads experiments and the report; switch roles on the next project.
  • Review each other's work. Before submitting, each partner reads and runs the other's code and edits the other's sections of the report.

Each report should end with a short Contributions paragraph stating what each partner did.

Submission Guidelines

These apply to every project. Each project's release slides list the specific results its report must include.

Submit one zip file per group on Canvas, named student1_student2_pN.zip (for example, smith_lee_p1.zip) and no larger than 300 MB. It must contain:

  1. Report.pdf: your report, typeset in LaTeX using the IEEE Transactions or Conference format.
  2. PN.txt: the link to your Google Colab notebook (for example, P1.txt). Set the notebook's sharing to Anyone with the link so it can be opened for grading, but do not post or send the link to anyone outside your group.
  3. A PDF export of your Colab notebook with all outputs and results visible.

The report must:

  • Show the input and output images for each step of the pipeline, and the final results for every dataset. Put all images in Report.pdf.
  • Explain the design choices you made and how you handled difficult cases, as each project asks.
  • Cite collaborators and outside sources (see the Collaboration Policy) and end with a Contributions paragraph.

A reference PDF for each project is posted on Piazza.

Late Policy

This course is fast-paced, with concepts building on each other, so staying current is important. Late assignments incur a 20% penalty per day. You have a total of six late days to use across assignments, except the final project. Late days must be used as full days; for example, full credit on an assignment submitted two days late requires two late days. When using late days:

  1. Include "USING X LATE DAY(S)" in the submission title.
  2. Add a Canvas comment identifying the late-day usage.
  3. Keep track of the late days you have left.

A late penalty is applied when late-day usage is not identified in the Canvas submission.

Collaboration Policy

Collaboration is encouraged, but you must understand the difference between collaboration and cheating. You may discuss concepts with your partner and classmates on Piazza and in person, but submitted work must reflect your own understanding.

  • Cite collaborators by name at the top of the report, including relevant Piazza posts.
  • Do not share or copy code. Discussing concepts and how code works is permitted.
  • Free, publicly available books, papers, and webpages may be used as research materials; paid solution services may not.
  • Clearly and explicitly cite all outside sources and materials.

Uncited use of outside sources is treated as presenting another person's work as your own.

Use of AI Tools

You may not use generative AI tools (such as ChatGPT, Claude, Gemini, or Copilot) to write any text you submit, including your report. You may use them to check your own writing for errors such as spelling and grammar. Submitting AI-written text is treated as unauthorized assistance under the Honor Code.
