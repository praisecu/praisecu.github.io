## What this covers

PRAISe YouTube MCP is an internal tool used only by the PRAISe Lab at the
University of Colorado Boulder to manage the lab's own YouTube channel,
[PRAISe at CU](https://www.youtube.com/@praisecu). It is not offered to the
public, and only lab accounts sign in to it.

## Data the tool accesses

After a lab account signs in with Google, the tool can use the YouTube Data API
and YouTube Analytics API to:

- read the channel's videos, playlists, comments, captions and statistics;
- read the channel's YouTube Analytics reports;
- update video details, playlists and thumbnails, reply to comments, and upload
  videos, when a lab member asks it to.

## How data is stored and shared

- The sign-in token is stored only on the lab computer that runs the tool. It
  is never uploaded to a server we operate.
- Data returned by YouTube is used only to answer the lab member's request and
  is not sold, shared with third parties, or used for advertising.
- The tool's use of information received from Google APIs follows the
  [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
  including the Limited Use requirements.

## Removing access

Access can be revoked at any time from
[Google Account permissions](https://myaccount.google.com/permissions). Deleting
the token file on the lab computer also removes the tool's access.
